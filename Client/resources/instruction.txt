Справка.

Горячие клавиши:
F11 – включить/отключить полноэкранный режим.
+ – увеличить масштаб открытого файла анализа.
- – уменьшить масштаб открытого файла анализа.
R – сбросить масштаб открытого файла к настройкам по умолчанию.
Удержание S - голосовой ввод.

Работа с результатами анализа (сообщениями от системы):
Правый клик по ответу в чате – открыть файл анализа вместе с кодом, сгенерированным нейросетью (удобно для проверки корректности вычислений).
Левый клик по ответу в чате – открыть файл анализа в чистом виде (только результаты и графики, без кода).

Как работает система:
Приложение построено по клиент-серверной архитектуре, что позволяет переложить тяжёлые вычисления на сервер:
Автоматический мониторинг: Как только в базу данных поступают новые сведения, сервер автоматически проверяет их на наличие аномалий с помощью моделей машинного обучения.
Анализ по запросу: Вы можете отправить текстовый или голосовой запрос. Сервер поймёт задачу, напишет и выполнит код анализа, а затем вернёт вам готовый PDF-отчёт.
Голосовое управление: Вы можете надиктовать запрос – сервер распознает речь, выполнит анализ и при необходимости озвучит ответ.
