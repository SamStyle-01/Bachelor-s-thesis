# Bachelor-s-thesis
Программа состоит из 2 частей: клиент и сервер. Сервер написан на Python + FastAPI, клиент написан на C++ + Qt.
Приложение создано, чтобы осуществлять автоматический анализ данных. В приложение посылается запрос, а оно возвращает нам PDF-файл, открываемый в том же приложении и небольшой комментарий к нему. PDF-файл содержит в себе развёрнутый анализ данных. Работает приложение следующим образом:
1) Пользователь делает запрос в клиентском приложении (доступны голосовой и текстовый интерфейсы).
2) Сервер обрабатывает запрос. Выполняется следующая последовательность шагов:  
2.1) Если отправленное пользователем сообщение было голосовым, производится сначала транскрибирование аудиофайла.  
2.2) Производится проверка на корректность сообщения. Если сообщение не имеет смысла, либо использована нецензурная брань, то пользователю возвращается уведомление об этом и обработка запроса прекращается.  
2.3) Производится обработка запроса. На этом этапе активируется ядро Jupiter Notebook и создаётся файл блокнота Jupiter Notebook. И далее происходит рассуждение модели, которое тут же записывается в блокнот и исполняется. Модель может рассуждать 4 способами: start - первое сообщение, которое отправится в чат к пользователю, code - все ячейки с кодом, которые записываются в блокнот и сразу же выполняются (Если происходит ошибка, модель повторяет попытку написать корректный код. Также после выполнения каждой ячейки с кодом модель получает обратную связь, то есть получает на данные о результатах вычисления), markdown - текст, который модель пишет в блокноте, и tech - тоже код, однако этот код не будет отображён в конечной версии блокнота, однако нужен модели, чтобы понять структуру документа и понять, что делать в спорных ситуациях.
2.4) По завершению создания блокнота производится его конвертация сначала в HTML-файл, а затем и в PDF-файл.  
3) Если пользователь включил функцию голосового ответа, то сервер синтезирует речь по сообщению, которое отправится в чат.
4) Сервер отправляет PDF-файл с анализом (В 2 версиях: с кодом, если нужно что-то проверить, и без кода. Чтобы открыть версию без кода, нужно нажать на левую кнопку мыши, а с кодом - на правую), сообщение в чат с пользователем, а также голосовое сообщение, если оно было включено, на клиентское приложение. Если голосовой ответ имеется, то он будет сразу же воспроизведён в приложении клиента.
5) У пользователя в чате появляется новое сообщение, по нажатию на которое он может открыть файл с произведённым анализом данных.

Стоит упомянуть, что вычисления приложение способно выполнять как на локальной машине (если конфиденциальность превыше всего, а также если мощностей локальной машины достаточно), так и используя API облачных моделей (достаточно заменить все вхождения одного класса на его альтернативу в коде сервера). На сервере находятся 3 нейросети: для распознавания речи, для текстовой обработки, для синтеза речи. Модели для распознавания речи и её синтеза обеспечивают голосовой интерфейс приложения.

Чтобы программа работала полноценно в минимальной комплектации, необходимо, чтобы одновременно работало 4 компонента: сервер, клиент, служба PostgreSQL, служба для передачи трафика на сервер (или белый API) (я использую CloudPub).

1) Загрузить базу данных в PostgreSQL. Файл с базой данных прилагается: pg_database.backup.
2) Запустить CloudPub. Создать публичный адрес, связав его с локальным http://localhost:8000/. Это нужно для того, чтобы к серверу можно было обращаться из интернета.
3) В файле .env в папке Server необходимо указать свой API-ключ от облачной модели. Я использую агрегатор https://polza.ai/.
4) Запустить сервер. Необходимо подготовить виртуальную среду окружения. Файл requirments.txt прилагаю.
5) Запустить клиент. В папке resources есть файл url.cfg. Заменить значение внутри него на актуальный публичный адрес из CloudPub. Если клиенту достаточно обращаться к серверу на том же компьютере (для теста, к примеру) по localhost, то можно заменить значение на http://localhost:8000/. 2 варианта запуска клиента: установить приложение или запустить в Qt Creator. Установщик имеется. Если запуск производить в Qt Creator, необходимо добавить следующие дополнительные компоненты помимо основных: Qt Multimedia, QtWebSockets, QtPdf.

Чтобы запустить клиент, необходимо установить приложение Валерий AI или запустить код клиента в Qt Creator, предварительно установив все необходимые компоненты.
